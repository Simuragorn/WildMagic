# Модульный 3D-тролль

Сцена `TrollDamagePrototype` теперь собирает технического low-poly тролля из шести независимо повреждаемых сегментов:

- голова;
- корпус;
- левая и правая руки;
- левая и правая ноги.

У каждого сегмента есть отдельные совпадающие меши кожи, плоти и кости. Первое попадание открывает плоть, второе — кость, третье отсоединяет выбранную часть и включает для неё физику. По упавшей части можно продолжать стрелять. Повреждения одного сегмента не переносятся на остальные.

Модель генерируется локально скриптом `Tools/Blender/build_modular_troll_layers.py`. Это технический манекен для проверки архитектуры повреждений и отсечения; финальные пропорции, лицо, топология и риг будут отдельным художественным этапом.

Управление в тестовой сцене:

- ЛКМ — выстрел в выбранную часть тела;
- R — полностью восстановить тролля.

Контрольный кадр сохраняется в `Artifacts/ModularTrollPrototypePreview.png` через меню `Wild Magic/Capture Modular Troll Prototype`.
